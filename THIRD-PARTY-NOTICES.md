# Third-party software

The packaged extension (`tex-visual.vsix`) bundles the following projects. Their licenses apply
to the respective parts of `media/`.

| Project | Used for | License |
|---|---|---|
| [CodeMirror 6](https://codemirror.net) | the editor | MIT |
| [KaTeX](https://katex.org) (code and fonts) | math rendering | MIT (fonts: SIL OFL 1.1) |
| [PDF.js](https://mozilla.github.io/pdf.js/) | drawing PDF figures | Apache-2.0 |
| PDF.js standard fonts (Foxit, Liberation) | text in PDF figures without embedded fonts | see `media/standard_fonts/LICENSE_FOXIT` and `LICENSE_LIBERATION` |
